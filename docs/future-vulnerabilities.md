# Planned Educational Scenarios

The following are ideas for future educational scenarios only. None of these vulnerabilities is implemented in BreachLab Version 0.1:

- SQL injection
- Broken access control
- Insecure direct object references (IDOR)
- Weak authentication
- Insecure API endpoints
- Exposed files
- Poor password storage

These scenarios will only exist inside the isolated BreachLab environment. They must not be used to target systems or networks without explicit authorization. A future exercise should include clear learning goals, a safe local setup, remediation guidance, and a retest before it is considered complete.
