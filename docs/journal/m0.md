## 3. What I Learned
I learned that Docker lets us run applications in separate containers without needing a full virtual machine for each one. Docker Compose makes it easier to manage those containers together.

I also learned about network segmentation and why the website should be able to reach the database while an attacker can't. We'll build this in M1.

Lastly, I learned that just because something is running doesn't mean it's fully tested. We need to actually verify that things work instead of assuming they do.
