# BreachLab — Milestone 1 Journal: Docker Network Setup

_Completed: 2026-11-17_

## 1. What I Did
I worked on the Docker setup for BreachLab. I separated the containers into frontend and backend networks so the attacker can access the web application but not directly access the database. I also fixed OBS-01 by binding the web app to localhost only, and added an attacker container on the frontend network.

## 2. What I Verified
I reviewed the Docker Compose configuration and checked that the network setup was correct. From inside the attacker container, I confirmed it can reach the web app but can't find or connect to the database. nmap showed the database port as filtered and the web port as open. I also confirmed the database has no internet access, and that the app and data still work after rebuilding.

## 3. What I Learned
I learned how Docker networks help control which containers can communicate with each other. I also learned that `sleep infinity` keeps the attacker container running so I can execute tools inside it. Without it, the container would shut down because it has nothing to run.

## 4. What's Next
For M2, I will work on implementing a real login system and authorization. This will include managing user sessions, roles, and making sure users can only access what they are allowed to.
